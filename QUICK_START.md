# 🚀 QUICK START GUIDE

## Get Running in 3 Steps!

### Step 1: Extract
Unzip `bridgehive_final_COMPLETE.zip` to your desired folder.

### Step 2: Install
```bash
cd bridgehive_final
pip install -r requirements.txt --break-system-packages
```

### Step 3: Run
```bash
python app.py
```

Then open: **http://localhost:5000**

---

## ✅ What Works Right Away

### Privacy Controls
1. **Settings > Privacy > Profile Visibility**
   - Change to Private/Public/Friends
   - Immediately protects your profile

2. **Settings > Privacy > Activity Status**
   - Toggle ON to show "Active Now" badge
   - Toggle OFF to hide it

### Quest Video
1. **Rewards > Quests > Introduction to Scams**
   - Click to watch educational video
   - Wait 30 seconds for timer
   - Click "Claim Points"
   - 🎊 **Enjoy confetti celebration!**

### Dark Theme
1. **Settings > Visual & Display > Dark Mode**
   - Toggle ON
   - All pages turn dark with good contrast
   - No more bright white screens!

### Language
1. **Settings > Language > Display Language**
   - Choose: English, 中文, Bahasa, தமிழ்
   - Page reloads in selected language
